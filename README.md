# Einkaufsliste

Ein kleines Python-Übungsprojekt für die Konsole. Das Programm kann Einträge zur Einkaufsliste hinzufügen, anzeigen und wieder entfernen. Die Liste kann auch vollständig geleert werden.

## Starten

Python 3 muss installiert sein. Starte die Datei im Terminal mit:

```bash
python einkaufsliste.py
```

## Dabei geübt

- Listen
- while-Schleifen
- Bedingungen mit if und elif
- Benutzereingaben mit input()
